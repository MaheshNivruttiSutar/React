# Section 31 — MSW (Mock Service Worker)

Learn how to mock API requests in the browser using [MSW](https://mswjs.io/) with React and Vite.

The app fetches users from [DummyJSON](https://dummyjson.com/docs/users) and can switch between **real API data** and **mock data** without changing application code.

## Prerequisites

- Node.js 18+
- npm

## Setup

```bash
cd section-31-MSW
npm install
npx msw init public
```

The `msw init` command copies `mockServiceWorker.js` into `public/`. That file must be committed — it is required for browser mocking.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server (uses `.env` setting) |
| `npm run mock` | Start dev server with MSW **always enabled** |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Real API vs mock data

Create a `.env` file in the project root:

```env
# FALSE = real API data from dummyjson.com
# TRUE  = MSW intercepts requests and returns mock data
VITE_ENABLE_MSW=FALSE
```

| `VITE_ENABLE_MSW` | What you see |
|-------------------|--------------|
| `FALSE` | Real users from `https://dummyjson.com/users` |
| `TRUE` | Mock users from `src/msw/mockDb.js` (John Doe, Jane Smith) |

Restart the dev server after changing `.env`.

**Tip:** `npm run mock` forces MSW on regardless of `.env`.

## Project structure

```
section-31-MSW/
├── public/
│   └── mockServiceWorker.js   # MSW service worker (generated by msw init)
├── src/
│   ├── App.jsx                # Fetches and displays users
│   ├── main.jsx               # Starts MSW before rendering (when enabled)
│   └── msw/
│       ├── browser.ts         # setupWorker for browser
│       ├── handler.js         # Request handlers (mock responses)
│       └── mockDb.js          # Mock user data
└── .env                       # Toggle MSW on/off (not committed)
```

## How it works

1. `main.jsx` checks `VITE_ENABLE_MSW`. If `TRUE`, it calls `worker.start()` and waits before rendering the app.
2. `App.jsx` fetches `https://dummyjson.com/users` on mount.
3. When MSW is enabled, `handler.js` intercepts that request and returns `mockDb` instead of hitting the network.
4. When MSW is disabled, the request goes to the real DummyJSON API.

## Troubleshooting

**`Unexpected token '<', "<!DOCTYPE "... is not valid JSON`**

- MSW is off and the fetch URL is wrong (use `https://dummyjson.com/users`, not `/docs/users`).
- Or MSW is on but the app rendered before `worker.start()` finished — restart the dev server.

**MSW not intercepting**

- Confirm `[MSW] Mocking enabled.` appears in the browser console.
- Run `npx msw init public` if `mockServiceWorker.js` is missing.
- Hard-refresh the page (Cmd+Shift+R) to reload the service worker.
