# 15 — getBy vs findBy vs queryBy

**Self-check question:** Do you know the difference between `getBy`, `findBy`, and `queryBy`?

## Topics to cover

- `getBy*` — element must be present (throws if not)
- `queryBy*` — returns `null` if not found (for asserting absence)
- `findBy*` — async, waits for element to appear
- When to use each and query priority order
