# React 19 - All New Features

## Quick Overview

A comprehensive guide to all new features in React 19, including Actions, the use() hook, ref as prop, Context improvements, document metadata, and more.

## What You'll Learn

- Actions: useActionState, useOptimistic, useFormStatus
- use() hook for Promises and Context
- ref as a regular prop (no forwardRef)
- Context as Provider directly
- Document metadata support
- Stylesheet and script management
- Resource preloading APIs
- Better error reporting
- Custom Elements support

## Time to Complete

Approximately 40-50 minutes (comprehensive overview)

## Prerequisites

- React fundamentals (components, hooks, state)
- Understanding of async/await
- Basic form handling

## Feature Categories

### Forms & Data
- **useActionState**: Form state with pending
- **useOptimistic**: Instant UI feedback
- **useFormStatus**: Nested form components

### Resources
- **use()**: Read Promises/Context conditionally
- **Suspense**: Enhanced async handling

### Components
- **ref as prop**: No more forwardRef
- **Context as Provider**: Simpler syntax

### DOM
- **Metadata**: Native title/meta/link
- **Stylesheets**: Precedence control
- **Scripts**: Async handling
- **Preloading**: prefetch, preconnect, preload

### DX
- **Better errors**: Improved reporting
- **Custom Elements**: Full support

---

**Tip**: Start with useActionState for forms and use() for data fetching - these provide the biggest immediate improvements to your code!
