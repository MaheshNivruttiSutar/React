# Weather App

## Quick Overview

Build a weather application with search functionality, API simulation, loading states, and error handling.

## What You'll Learn

- Managing multiple related state variables
- Async/await patterns in React
- UI state machines (loading/error/success)
- Mock data for development
- Gradient and glass-morphism CSS

## Time to Complete

Approximately 25-35 minutes

## Prerequisites

- useState hook
- Async JavaScript (Promises, async/await)
- Conditional rendering
- CSS basics

## Features

- City search input
- Quick search buttons
- Loading indicator
- Error messages
- Weather data display
- Beautiful UI with gradients

## API Note

This example uses mock data. To use a real API:
1. Sign up at OpenWeatherMap
2. Get an API key
3. Replace mock fetch with real API call

---

**Tip**: Master the loading/error/success pattern - it's used in almost every app that fetches data!
