# JSX Basics

## Quick Overview

**JSX** is a syntax extension that lets you write HTML-like code in JavaScript. It makes components easier to read and write.

## 📚 What You Need to Know

- JSX looks like HTML but is actually JavaScript
- Babel transforms JSX into React.createElement() calls
- You must have a single root element
- Use `className` instead of `class`
- Close all tags, even self-closing ones with `/>`
- Use curly braces `{}` to embed JavaScript expressions
