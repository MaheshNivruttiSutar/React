# What is a Component?

## Quick Overview

A **component** is a reusable piece of UI built with JavaScript that returns HTML-like syntax (JSX).

## 📚 What You Need to Know

- Components are just JavaScript functions
- They return JSX (looks like HTML)
- Components are **reusable** and **composable**
- Use PascalCase for component names: `UserCard`, not `userCard`
- Keep components focused - do one thing well
