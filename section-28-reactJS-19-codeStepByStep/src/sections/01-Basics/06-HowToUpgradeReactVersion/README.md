# How to Upgrade React Version

## Quick Overview

Learn how to check and upgrade your React version safely.

## What You'll Learn

- Check current React version
- Upgrade steps
- React 19 migration
- Troubleshooting common issues

## Time to Complete

Approximately 10-15 minutes

## Key Commands

```bash
# Check version
npm list react

# Upgrade to latest
npm install react@latest react-dom@latest

# Clean install
rm -rf node_modules && npm install
```

---

**Tip**: Always create a git branch before upgrading and test thoroughly after!
